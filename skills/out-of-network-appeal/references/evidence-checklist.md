# Evidence checklist: out of network

Report missing evidence using these vocabulary IDs (the full list is in the `submit_findings` tool schema).

| ID | When it's needed |
|---|---|
| `eob` | Usually. Shows how the claim was processed. |
| `emergency_records` | Emergency or urgent care: shows the symptoms and the care given. |
| `network_adequacy_evidence` | Network-gap argument: who the member contacted, distances, wait times. |
| `network_status_proof` | Directory-error argument: the directory listing at the time care was scheduled or received. |
| `medical_records` | Continuity of care: shows the ongoing treatment or pregnancy stage. |
| `pcp_referral` | Plans that require a referral for specialist care or for a network exception (check the plan's appeals section and referral rules). |
| `itemized_bill` | Helpful for balance-billing disputes; required only if the plan asks for it. |

## How to decide what is missing

1. **Required** = items the plan's appeals section lists for out-of-network denials (including any conditional items, such as a referral) + items the denial letter says were missing + the item that proves the protection you rely on.
2. **Has** = items the member already has (the "What I have so far" list in their note). Match by meaning, not exact wording.
3. **Missing** = required − has.
