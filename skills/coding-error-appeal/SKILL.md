# Coding error appeal

A coding denial usually means the service was fine but the claim described it wrong. The fix is normally a **corrected claim** from the provider; the member's appeal supports it and asks that the member not be billed meanwhile.

## 1. Read the plan's claims and coding rules

Search for: coding standards, bundled or same-day services, duplicate claims, corrected claims, and the coverage section for the service (e.g. preventive care rules can decide a coding dispute).

## 2. Identify the coding problem

| Denial says | What is usually wrong | Fix |
|---|---|---|
| Office visit included in a same-day procedure | Missing modifier 25 for a significant, separately identifiable visit | Corrected claim with modifier 25 |
| Duplicate of a service already paid | A service on both sides of the body or repeated the same day, billed without RT/LT, 50 or 59 | Corrected claim with the right modifier |
| Invalid or non-billable diagnosis code | Code deleted or not specific enough on the date of service (e.g. a parent code replaced by more specific child codes) | Corrected claim with a valid, specific code |
| Place of service doesn't match | Wrong POS code (e.g. hospital outpatient vs. office) | Corrected claim |
| Units exceed the maximum | Units entered as milligrams instead of the code's unit size | Corrected claim with the right units |
| Component tests of a panel | Panel parts billed separately (unbundling) | Pay as the panel; the member shouldn't be billed for the bundled parts |
| Screening processed as diagnostic | A screening that became therapeutic (e.g. polyp removed) missing the screening modifier or diagnosis | Reprocess as preventive with no cost sharing |

Check whether the plan says the member isn't responsible while a coding error is corrected, or can't be billed for bundled services. That protects the member right away.

## 3. Judge viability

Coding appeals are usually viable when the service matches what was actually done. They are not viable if the service genuinely wasn't covered and the coding was correct; then the denial is really a different type.
